    How this review works

    Calculation choices, reproducibility, and safety boundaries.

    Deterministic browser model

    Calculation

    Each location has a synthetic activity index, drift, and dispersion. The browser generates seeded lognormal paths and derives comparison summaries. The hazard panels are deterministic sensitivity views, not eruption forecasts.

    Reproducibility

    The observation snapshot is committed with the source. The same location, controls, and seed produce the same result.

    Limits

    • No observatory, satellite, seismic, gas, or civil-protection feed is connected.
    • The activity index has no operational alert-level meaning.
    • The model is not a Hawkes-process fit and has no demonstrated forecast skill.
    • Always use the responsible monitoring agency for current hazards.
